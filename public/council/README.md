# Union MEC Council Photos Directory

Place portrait/passport photos of the elected Union MEC Office Bearers and Executive Council members here.
Any image placed in this directory (`public/council/`) is automatically served by the application.

## Supported Formats
- `.jpg` or `.jpeg`
- `.png`
- `.webp`

Recommended resolution: **Square or 4:3 / 16:10 portrait** (e.g. 600x600px or 800x1000px).
